# 学生学习路线

先用 `smoke` 跑通，再读方程与调用流程，最后修改网格和物理输入。不要把0.2秒的
工作流检查或600秒的粗网格算例，当成已经复现分叉或匹配香港观测。

## 第一遍：理解模型在算什么

1. 阅读 [METHODS.md](METHODS.md) 和 [方法文档](../methodology/main.pdf)。
   密度、沿场动量和电势是耦合的：不是先生成一个固定速度场再一直推进密度。
2. 区分 `N=n/1e12` 和真实密度m^-3；动量变量是 `M=N*u_parallel`。
3. 沿场电势近似常数，电势方程积分覆盖完整共轭磁通管。E层的真实分子离子参与闭合，
   不能用局部F层耗空后的密度替代整条磁力线的积分电导。
4. 夜间模式有O+、NO+、O2+和共同Ne；默认非夜间模式的分子背景是固定的。
   `night-reactions=0`只关闭反应，仍然输运分子离子。
5. 温度、中性大气和B是给定的；没有能量方程、完整光化学和中性风演化。

## 第二遍：沿主调用链读代码

* `main.c`：解析参数、检查组合、选择静态参考或AMR入口。
* `amr3_run`：输出时钟、重网格、化学半步、预测/校正、回滚和接受。
* `rhs`：`a3_prepare -> a3_potential -> a3_transport -> a3_night_transport`。
* `a3_prepare`：交换halo、绑定当前时间层、重置惰性重构缓存、限制/重构、刷新分子电导和Ne。
* `a3_potential`：沿场积分完整张量、约束节点装配、求解并检查真实残差。
* `a3_transport`：从这一时间层的电势得到面速度和通量，再加沿场压力/重力。
* 第二次RHS必须使用预测后的所有物种；不能混用旧电势和新密度。

预测/校正中的指数系数只允许在同一尝试的dt和碰撞频率下复用。化学或预测改变状态后，
压力对数、Ne和电导响应都要重新对应当前状态。注释说明了这些缓存何时有效。

## 第三遍：理解几何和AMR

先看 `igrf.c -> geometry.c -> pdm.c`，再读
`amr3_mesh.c -> amr3_macro.c -> amr3_structure.c -> amr3_adapt.c`。

* 地理经度不等于磁通管apex经度；350km大地高度也不等于350km球形高度。
* 用户Nx、Ny表示物理L0根网格。两级最细2Nx×2Ny，三级4Nx×4Ny；ns不加密。
* 三级内部level=-1/0/1，对应输出物理L0/L1/L2。
* 活动密度单元、存储槽位、电势自由度和canonical显示单元不是同一件事。
* 粗网格区域的显示重构，不等于那里实际演化过细网格自由度。
* 细化跟踪残差梯度、曲率、速度变化和信息损失；coarsening还要满足60秒静默/驻留时间。
* 早期小扰动需要从初始化就有足够分辨率，或明确启用seed保护。AMR不能恢复已经被抹掉的扰动。

PDM4的4指四个单元的空间重构模板；beta是限幅参数。它与沿场重构阶数、二阶时间积分
分别控制不同的数值误差。PDM4既不是PDM7，也不表示完整耦合模型有四阶收敛。

## 第四遍：守恒、并行和输出

看 `a3_mass/a3_remap/a3_valid`，了解粒子、带符号动量、marker、边界通量和反应账本。
再看 `amr3_migration.c` 的旧/新拥有区交集；MPI通信完成之前不能覆盖发送状态。

OpenMP只覆盖已经按写入归属审计的循环。分子面循环按整行/列分工，保持k连续访问。
O+ AMR面循环涉及粗细接触和惰性缓存，不能照搬一个pragma；把所有面同时并行会写冲突。
MPI/PETSc调用留在主线程。必须为每个rank分配足够的核，单核绑核下开4线程没有意义。

读取 `frames.csv` 和 `structure_frames.csv` 再解码二进制。
`retries=0`不代表没有化学后CFL缩步；看新的调用分类计数。
分阶段计时有嵌套，不能相加凑100%。性能必须给物理推进长度、输出频率、rank/线程数和
完整进程退出等待。更多预留CPU不等于已经使用同样多的计算线程。

## 建议练习

1. 不改物理，先改变输出目录和输出频率，检查读出的帧时间是否真实。
2. 在固定两级布局中检查跨粗细界面粒子守恒，再看动态细化/粗化。
3. 同一存档改变MPI数，比较保存场、真实残差和守恒，而不只看一张相似的图。
4. 改变beta或背景电导属于新数值/物理实验，保留旧输入与结果，避免混进性能优化。
5. 对香港/三亚ISR，先用真实ECEF网格确认天顶150-800km位置，再讨论泡是否穿过观测区。
